# **📊 Dashboard TechPulse: Análise Estratégica de E-commerce**

Este repositório contém o projeto de Business Intelligence desenvolvido de ponta a ponta para a **TechPulse Electronics**, uma empresa simulada de varejo eletrônico. O projeto demonstra habilidades em ETL, modelagem dimensional (Star Schema), cálculos avançados em DAX e storytelling visual.

## **🎯 Objetivo do Projeto**

Transformar dados brutos de vendas em insights acionáveis para a diretoria, focando em quatro pilares:

1. **Monitoramento de Receita e Lucro:** Visão geral da saúde financeira.  
2. **Performance de Portfólio:** Identificação de categorias e produtos líderes.  
3. **Inteligência Geográfica:** Mapeamento de vendas por estados brasileiros.  
4. **Eficiência de Canais:** Análise de ROI por canal de marketing.

## **💻 Tecnologias Utilizadas**

* **Power BI:** Visualização e dashboarding.  
* **Power Query:** Limpeza e normalização de dados (ETL).  
* **DAX:** Implementação de métricas de negócio.  
* **Markdown:** Documentação técnica e governança.

## **📂 Estrutura do Repositório**

* /dados: Arquivos CSV utilizados como base de dados.  
* /documentacao: Dicionário de dados detalhado.  
* TechPulse\_Vendas.pbix: Arquivo original do Power BI.

## **🚀 Resultados do Dashboard (Insights Atuais)**

Com base nos dados analisados, o dashboard reporta:

* **Faturamento Total:** R$ 85,94 mil.  
* **Rentabilidade:** Lucro de R$ 28,15 mil com uma **Margem de 32,75%**.  
* **Categorias:** Notebooks e Smartphones lideram o volume financeiro.  
* **Canais:** Google Ads apresenta-se como o canal de maior conversão de receita.
